rust-thanos

删除未使用的区块，让世界更小、更流畅。

高效的 Minecraft Java 世界优化工具，Rust 版 OrzMCBackup。检测并清理未被使用的区块、压缩世界体积；merge 命令可将优化后的世界安全合并回完整备份。

在 GitHub 上查看 下载 Release 快速开始

特性

  • ·智能区块检测 — InhabitedTime 阈值、强加载区块与 keep-range 多通道判定取并集
  • ·多压缩格式 — RAW / ZLIB / GZIP / LZ4 Block，含校验
  • ·数据安全 — 损坏区块安全保留，绝不丢数据；解压上限防炸弹
  • ·merge 合并恢复 — 按区块槽合并回完整备份，entities / poi 锁步
  • ·跨平台 — macOS / Linux / Windows × arm64 / x86_64 独立二进制
  • ·脚本友好 — JSON / CSV / Text 报告，--strict 退出码，--dry-run 演练

快速开始

Homebrew

# 添加私有源并安装
$ brew tap orzgeeker/core && brew install rust-thanos

从源码构建

$ git clone https://github.com/OrzMC/rust-thanos.git
$ cd rust-thanos && cargo build --release

下载预编译二进制

# macOS / Linux (.tar.gz) 与 Windows (.zip)，arm64 / x86_64
# 见 https://github.com/OrzMC/rust-thanos/releases

用法

# 优化世界：裁剪为只剩在用区块
$ rust-thanos backup /path/to/world /path/to/backup -t 600

# 合并恢复：把优化后的世界合回完整备份
$ rust-thanos merge /path/to/world /path/to/backup /path/to/restored
